# Profile Image and Tag Editor

## Purpose
- Support the reusable input behavior inside the developer profile page.

## Profile Image
- Select image file
- Upload request state
- Preview refresh on success
- Error state on failure

## Search Tags
- Add tag from input
- Remove tag with `x`
- Max 5 tags
- Duplicate tag protection

## API Relation
- Image upload uses a separate endpoint.
- Tag list is saved through the profile save request.
