# Application Form and Contact Blocking

## Purpose
- Separate outsourcing and onsite application behavior.
- Show clear feedback when contact information is blocked.

## Outsourcing Rules
- Working days input
- Bid amount input
- Proposal text input

## Onsite Rules
- At least one position row
- Skill category, career level, head count, monthly pay
- Proposal text input

## Validation Feedback
- Show server validation near the proposal field or as a toast.
- Disable submit while the request is being processed.
