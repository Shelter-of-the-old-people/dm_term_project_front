# Project Detail and Application Page

## Purpose
- Show the project summary required by the assignment.
- Let the developer submit an outsourcing or onsite application.

## Shared Summary Area
- Title
- Outsourcing / onsite badge
- Recruitment state
- Budget
- Expected duration
- Applicant count
- D-day
- Tech stack

## Outsourcing Form
- Working days
- Bid amount
- Proposal text

## Onsite Form
- Position rows
  - Skill category
  - Career level
  - Head count
  - Monthly pay
- Proposal text

## Rules
- Render the form that matches the project type.
- Show backend validation messages for contact blocking.
- Prevent duplicate submission while the request is pending.
