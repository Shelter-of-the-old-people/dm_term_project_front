# Client Project Create Page

## Purpose
- Allow a client user to register a project.

## Form Fields
- Title
- Recruitment deadline
- Project type
- Budget
- Expected duration
- Project fields
- Planning status
- Meeting region
- Work description
- Progress method
- Tech stack tags

## UX Notes
- Multi-select for project fields
- Tag input for tech stack
- Save button with loading state
- Redirect to project management after success
