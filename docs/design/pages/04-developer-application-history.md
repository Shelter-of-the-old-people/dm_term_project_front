# Developer Application History Page

## Purpose
- Let a developer review submitted applications and read the full content again.

## List View
- Project title
- Proposal or quote summary
- Applicant count
- Expected duration
- Detail action

## Detail View
- Project summary
- Submitted application data
- Close button

## State
- History loading state
- Empty state
- Selected application detail loading state

## APIs
- `GET /api/developer/applications`
- `GET /api/developer/applications/{applicationId}`
