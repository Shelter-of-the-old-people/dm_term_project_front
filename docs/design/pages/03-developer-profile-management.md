# Developer Profile Management Page

## Purpose
- Allow developers to edit the profile required by the assignment.

## Form Sections
- Profile image upload
- Support fields
- Activity availability
- Onsite availability
- Region (2-level selection)
- Business type
- Career years
- Search tags
- Introduction text

## Data Flow
1. Load the current profile.
2. Upload the image separately.
3. Save the rest of the form fields.

## Validation
- Search tags max 5
- Duplicate tags blocked
- Show upload and save progress

## User Feedback
- Show immediate preview after image upload.
- Show clear success and failure messages.
