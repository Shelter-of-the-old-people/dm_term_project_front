# DM Term Project Frontend

## Overview
- This repository contains the frontend for the 2026 term project based on the Freemoa clone assignment.
- The current codebase started as a one-page visual clone of the Freemoa landing page.
- The target implementation is a role-based SPA that works with the backend repository through session-based authentication.

## Tech Stack
- React 19
- TypeScript
- Vite
- Tailwind CSS 4

## Current Status
- Landing page prototype exists.
- Mock project board exists for visual exploration.
- Design documents for the real term-project scope live under `docs/design`.
- Real backend integration, login flow, role-based mypages, project detail flow, and application forms are still to be implemented.

## Commands
- `npm run dev`
- `npm run build`
- `npm run lint`

## Important Notes
- The final project must behave as a client-side rendered SPA.
- Project list sorting and pagination must be handled by backend responses, not by client-side sorting in the final implementation.
- Authentication must use session cookies, not JWT.
